Mapa de calor das 72 matrizes

Cada quadradinho é uma matriz do DINOv2. Quanto mais escura a cor, maior o valor daquela medida. Os três mapas usam a mesma escala, então dá para comparar as cores entre eles.

Escala em raiz quadrada: realça diferenças pequenas. Os valores abaixo de cada tom são os reais.

Como ler

Linhas: os 12 blocos. O bloco 0 está no começo da rede, perto da foto crua, e o 11 está no fim, perto da cabeça. Colunas: o tipo de matriz. As quatro primeiras são da atenção (a roda de conversa), as duas últimas são do MLP (pensar sozinho). A linha tracejada embaixo é a média de cada coluna.

Os três mapas: o primeiro compara o modelo original com o treino 1, o segundo com o treino 2, e o terceiro compara o treino 1 com o treino 2. Esse terceiro é o piso de ruído: o que muda só por acaso entre duas rodadas.

Cuidado ao interpretar

Os dois primeiros mapas são quase iguais (correlação – entre as 72 células). Isso não prova que o padrão é reprodutível, porque o mapa de ruído, o terceiro, mostra o mesmo desenho por tipo de matriz, só com cores mais claras.

Dados reais de resultado.json, resultado_s1.json e resultado_ruido.json, embutidos nesta página. Duas sementes bastam para existir um piso de ruído, mas não para ter confiança estatística.
